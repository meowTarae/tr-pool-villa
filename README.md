# TR 풀빌라

강원도 홍천의 프라이빗 풀빌라를 소개하는 한 페이지 홍보 사이트입니다. 예약과 결제는 야놀자로 넘기고, 이 페이지는 공간과 머무는 방식을 보여 줍니다.

## 구성

- 첫 방문 시 여름 성수기 예약 안내 팝업
- PROLOGUE, ROOMS, FACILITIES, RESERVATION, LOCATION, FAQ
- 가상 방문 후기 4개와 문의 폼
- 카카오톡, 인스타그램, 야놀자 버튼. 링크는 연결하지 않음
- 사진은 교체할 자리만 표시

## 실행

```bash
npm install
npm run dev
```

개발 서버는 `http://127.0.0.1:43123` 에서 열립니다.

```bash
npm run build
npm run lint
```

## 사진 교체

`data-image-slot` 속성이 있는 요소가 사진 자리입니다. 각 자리의 문구가 어떤 장면인지 알려 줍니다. 가로 장면은 16:10, 프롤로그 사진은 3:4, 첫 화면은 화면 전체를 채웁니다.
